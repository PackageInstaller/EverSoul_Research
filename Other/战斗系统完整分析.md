## 1. 战斗流程总览

### 1.1 交互处理流程

战斗中的每次交互（Interact）按以下顺序处理：

1. **查找目标单位** - 在战场上定位施法者和目标
2. **遍历技能代码列表** - 处理每个技能代码（SkillCodeData）
3. **检查前置条件** - `IsTargetBeforeConditionCleared` 验证条件是否满足
4. **获取交互数据** - `GetInteractionData` 计算伤害/治疗/魔法等数值
5. **累积结果** - 将各技能代码的效果累加
6. **应用交互结果** - `ApplyInteractionResult` 实际修改单位属性
7. **触发被动反应** - 处理目标的被动技能响应
8. **应用击退效果** - 如果有移动效果则改变单位状态

### 1.2 技能代码效果类型

技能代码通过 `SkillEffect` 枚举定义，主要类型：

| 类型编号 | 效果名称      | 说明             |
| -------- | ------------- | ---------------- |
| 2        | AtkPerDmg     | 攻击力百分比伤害 |
| 7        | BaseAttack    | 普通攻击         |
| 30       | BuffEffect    | Buff效果         |
| 32       | LifeSteal     | 生命偷取         |
| 33       | Critical      | 暴击             |
| 46       | ForceCritical | 强制暴击         |
| 47       | ForceEvade    | 强制闪避         |
| 300      | BuffAdd       | 添加Buff         |

## 2. 伤害计算系统

### 2.1 伤害计算总流程

```
原始伤害值
  ↓
应用防御减伤
  ↓
应用种族相克系数
  ↓
应用抗性减伤
  ↓
应用暴击（如果触发）
  ↓
应用伤害倍率（DamageRate）
  ↓
应用技能类型倍率
  ↓
应用伤害上限
  ↓
确保最小伤害（至少为1）
```

### 2.2 伤害类型详解

#### 2.2.1 基于攻击力的伤害

**AtkPerDmg (2)** - 攻击力百分比伤害

```
伤害 = 施法者攻击力 × 技能系数
```

**IgnoreInvincibleAtkPerDmg** - 无视无敌的攻击力百分比伤害

- 即使目标有无敌Buff也能造成伤害

**NoMissAtkPerDmg** - 必中的攻击力百分比伤害

#### 2.2.2 基于生命值的伤害

**MaxHpDmg** - 施法者最大生命值百分比伤害

```
伤害 = 施法者最大生命值 × 技能系数
```

**TargetMaxHpDmg** - 目标最大生命值百分比伤害

```
伤害 = 目标最大生命值 × 技能系数
上限 = 施法者攻击力 × HP_DMG_LIMIT (3.0)
最终伤害 = min(计算伤害, 上限)
```

**TargetMaxHpTrueDmg** - 目标最大生命值真实伤害

- 类似 TargetMaxHpDmg，但无视防御和抗性

**CurrentHpDmg** - 施法者当前生命值百分比伤害

```
伤害 = 施法者当前生命值 × 技能系数
```

**TargetCurrentHpDmg** - 目标当前生命值百分比伤害

```
伤害 = 目标当前生命值 × 技能系数
```

**TargetCurrentHpTrueDmg** - 目标当前生命值真实伤害

**CurrentHpPerDmg** - 当前生命值百分比 × 攻击力伤害

```
伤害 = (施法者当前生命值 / 施法者最大生命值) × 技能系数 × 施法者攻击力
```

**LoseHpPerDmg** - 损失生命值百分比 × 攻击力伤害

```
伤害 = [(施法者最大生命值 - 施法者当前生命值) / 施法者最大生命值] × 技能系数 × 施法者攻击力
```

#### 2.2.3 基于防御力的伤害

**DefPerDmg** - 防御力百分比伤害

```
伤害 = 施法者防御力 × 技能系数
```

#### 2.2.4 基于Debuff层数的伤害

**AtkPerBurnDmg** - 基于燃烧层数的伤害

```
伤害 = 施法者攻击力 × 技能系数 × 目标燃烧Buff抵抗率
```

类似的还有：

- **AtkPerPoisonDmg** (302) - 中毒
- **AtkPerElectricDmg** (303) - 电击
- **AtkPerBleedDmg** (304) - 流血
- **AtkPerFrostDmg** (305) - 冰霜
- **AtkPerCurseDmg** (306) - 诅咒

#### 2.2.5 特殊伤害类型

**AbsoluteDamage** - 绝对值伤害

```
伤害 = 技能系数（直接作为伤害值）
```

**IgnoreInvincibleAtkValueDmg** - 无视无敌的绝对值伤害

**RecordedDamagePerDmg** - 基于记录伤害的百分比伤害

```
从伤害记录列表中查找匹配类型
伤害 = 记录伤害 × 记录倍率 × 技能系数
```

### 2.3 防御减伤计算

**防御值计算：**

```cpp
if (穿透类型 == Defence(2) 或 All(4)):
    有效防御 = max((1 - 穿透率) × 防御值, 0)
else:
    有效防御 = max(防御值, 0)
```

**防御减伤公式：**

$$
\text{防御后伤害} = 
\begin{cases} 
\text{原始伤害} - \frac{\text{有效防御}}{\text{有效防御} + 0.3 \times \text{原始伤害}} \times \text{原始伤害}, & \text{有效防御} \geq 0 \\
\text{原始伤害}, & \text{有效防御} < 0
\end{cases}
$$

其中 `0.3` 是 `DAMAGE_FORMULA_KEY_VALUE` 常数。

### 2.4 抗性减伤计算

**抗性值计算：**

```cpp
// 根据攻击类型选择抗性
if (攻击类型 == Intelligence(魔法攻击)):
    基础抗性 = 目标魔法抗性
else:
    基础抗性 = 目标物理抗性

// 应用穿透
if (穿透类型 == 3 或 4):  // Resist或All
    有效抗性 = (1 - 穿透率) × 基础抗性
else:
    有效抗性 = 基础抗性
```

**抗性减伤公式：**

$$
\text{抗性后伤害} = \text{防御后伤害} \times \max(1 - \text{有效抗性}, 0.1)
$$

其中 `0.1` 是 `DAMAGE_RESIST_MIN` 常数，确保伤害不会被完全抵抗。

### 2.5 种族相克系统

**种族相克值计算：**

```cpp
// 1. 从种族相克表获取基础相克系数
基础相克 = RaceCounterTable[攻击者种族][防御者种族]

// 2. 如果是优势相克（系数>1.0），加上额外优势加成
if (基础相克 > 1.0):
    基础相克 += 攻击者属性.特殊攻击值[0x1ADE3]  // 优势加成

// 3. 加上针对特定种族的特殊攻击加成
特殊攻击 = 攻击者属性.特殊攻击值[防御者种族]
if (特殊攻击 != 0):
    相克系数 = max(基础相克 + 特殊攻击, 0.0)
else:
    相克系数 = max(基础相克, 0.0)
```

默认相克系数为 `1.0`。

### 2.6 暴击计算

**暴击触发：**

- 技能代码中 `EffectType == 33` 时标记为暴击
- 或技能代码中 `EffectType == 46` 时强制暴击

**暴击伤害：**

$$
\text{暴击后伤害} = \text{抗性后伤害} \times \text{暴击威力}
$$

暴击威力由角色属性 `CriticalValue` 决定。

### 2.7 技能类型倍率

根据技能来源应用不同的倍率：

| 技能来源 | RequestFrom        | 倍率字段          |
| -------- | ------------------ | ----------------- |
| 普通攻击 | BaseAttack (7)     | BaseAttackRate    |
| 被动技能 | NormalSkill (8)    | SubSkillRate      |
| 主动技能 | ActiveSkill (9)    | ActiveSkillRate   |
| 终极技能 | UltimateSkill (10) | UltimateSkillRate |

**应用公式：**

$$
\text{技能倍率后伤害} = \text{暴击后伤害} \times (1 + \text{技能倍率})
$$

### 2.8 伤害倍率

如果技能代码提供了伤害倍率（DamageRate）：

$$
\text{伤害倍率后伤害} = \text{暴击后伤害} \times (1 + \text{伤害倍率})
$$

### 2.9 伤害上限

对于基于生命值的伤害类型，应用伤害上限：

**适用类型：**

- TargetMaxHpDmg
- TargetMaxHpTrueDmg
- LifeSteal

**上限计算：**

```cpp
上限 = 施法者攻击力 × HP_DMG_LIMIT  // HP_DMG_LIMIT = 3.0
最终伤害 = min(计算伤害, 上限)
```

### 2.10 完整伤害计算公式

$$
\begin{aligned}
\text{最终伤害} = \max\Bigg( & (1 + \text{技能倍率}) \times (1 + \text{伤害倍率}) \times \text{暴击系数} \times \\
& \text{种族相克} \times \text{防御减伤} \times \max(1 - \text{有效抗性}, 0.1), \\
& \text{MIN\_DAMAGE} \Bigg)
\end{aligned}
$$

其中：

- **防御减伤** = 原始伤害 - [有效防御 / (有效防御 + 0.3 × 原始伤害)] × 原始伤害
- **暴击系数** = 暴击时为暴击威力，否则为1
- **MIN_DAMAGE** = 1（最小伤害值）

## 3. 治疗计算系统

### 3.1 治疗类型详解

#### 3.1.1 基于攻击力的治疗

**AtkPerHeal** - 攻击力百分比治疗

```
治疗量 = 施法者攻击力 × 技能系数
```

#### 3.1.2 基于最大生命值的治疗

**MaxHpHeal** - 施法者最大生命值百分比治疗

```
治疗量 = 施法者最大生命值 × 技能系数
```

**TargetMaxHpHeal** - 目标最大生命值百分比治疗

```
治疗量 = 目标最大生命值 × 技能系数
```

#### 3.1.3 基于损失生命值的治疗

**TargetLoseHpHeal** - 目标损失生命值治疗

```
治疗量 = (目标最大生命值 - 目标当前生命值) × 技能系数
```

**TargetLoseHpPerHeal** - 目标损失生命值百分比 × 攻击力治疗

```
治疗量 = [(目标最大生命值 - 目标当前生命值) / 目标最大生命值] × 技能系数 × 施法者攻击力
```

#### 3.1.4 特殊治疗类型

**AbsoluteHeal** - 绝对值治疗

```
治疗量 = 技能系数（直接作为治疗值）
```

**RecordedDamagePerHeal** - 基于记录伤害的百分比治疗

```
从伤害记录列表中查找匹配类型
治疗量 = 记录伤害 × 记录倍率 × 技能系数
```

### 3.2 治疗倍率

治疗量也会受技能来源的影响：

$$
\text{最终治疗量} = \text{基础治疗量} \times (1 + \text{技能倍率})
$$

技能倍率规则同伤害系统。

### 3.3 生命偷取

**LifeSteal (32)** - 生命偷取

```
伤害 = 目标最大生命值 × 技能系数
治疗 = 伤害（对目标造成伤害，同时治疗施法者相同数值）
上限 = 施法者攻击力 × 
```

## 4. 魔法系统

### 4.1 魔法（MP）获取类型

#### 4.1.1 绝对值魔法获取

**AbsoulteManaGain** - 直接获取指定MP

```
MP获取 = 技能系数
```

#### 4.1.2 魔法偷取

**ManaSteal** - 从目标偷取MP

```
偷取量 = 目标当前MP × 技能系数
目标MP减少 = -偷取量
施法者MP增加 = +偷取量
```

#### 4.1.3 魔法获取（带倍率）

**ManaGain** - MP获取（受倍率影响）

```
基础MP = 技能系数
MP获取 = GetRateChangedMPAmount(基础MP)
```

`GetRateChangedMPAmount` 会应用：

- Buff的MP获取倍率变化
- MP获取抗性等效果

### 4.2 战斗行为MP获取

以下行为会自动获取MP：

| 行为类型     | 基础MP获取 | 常数名称             |
| ------------ | ---------- | -------------------- |
| 普通攻击命中 | 200        | MP_CHARGE_ATTACK_HIT |
| 技能命中     | 400        | MP_CHARGE_SKILL_HIT  |
| 击杀敌人     | 1500       | MP_CHARGE_KILL       |

**MP获取公式：**

```cpp
if (初始MP >= 1):
    // 应用MP获取倍率Buff
    MP获取倍率 = GetTotalRateChangeValue(BuffRateChangeType_MPGain)
    最终MP = (MP获取倍率 + 1.0) × 初始MP

if (初始MP < 0 且 没有MP减少免疫Buff):
    // 允许MP减少
    最终MP = 初始MP
else if (初始MP < 0 且 有MP减少免疫Buff):
    // 免疫MP减少
    最终MP = 0
```

### 4.3 终极技能点数（UMP）系统

UMP是释放终极技能所需的特殊资源。

#### 4.3.1 UMP获取

| 行为     | UMP获取 | 常数名称                   |
| -------- | ------- | -------------------------- |
| 普通攻击 | 100     | BATTLE_UMP_ADD_ATTACK      |
| 被动技能 | 300     | BATTLE_UMP_ADD_SUBSKILL    |
| 主动技能 | 1000    | BATTLE_UMP_ADD_ACTIVESKILL |
| 击杀敌人 | 1000    | BATTLE_UMP_ADD_KILL        |
| 角色死亡 | 1000    | BATTLE_UMP_ADD_DEATH       |

#### 4.3.2 UMP消耗

```
终极技能消耗 = 10000  // BATTLE_UMP_COST
```

### 4.4 晕眩值（Groggy）系统

**GroggyGain** - 晕眩值获取

```
晕眩值 = 目标最大晕眩值 × 技能系数
```

当晕眩值达到最大值时，目标进入晕眩状态。

## 5. 护盾与Buff系统

### 5.1 Buff应用流程

**Buff添加条件：**

1. 技能代码 `EffectType` 为 300（BuffAdd）或 30（BuffEffect）
2. Buff类别不是 `2`（某种特殊类别）
3. 没有触发闪避
4. 如果施法者被魅惑，且目标单位类型与施法者不同，则特定Buff（208, 213）不生效

**Buff数据结构：**

```cpp
struct BuffData {
    int32_t No;              // Buff编号
    int32_t BuffEffect;      // Buff效果类型
    double Duration;         // 持续时间
    double Value;            // Buff数值
    int32_t Group;           // Buff分组
    int32_t OverlapLimit;    // 叠加上限
    int64_t BuffCategory;    // Buff类别
    String* ParticlePath;    // 特效路径
    int32_t ConditionId;     // 条件ID
    String* IconPath;        // 图标路径
    bool IsImportant;        // 是否重要
    int32_t BuffOrder;       // Buff显示顺序
};
```

**Buff请求：**

```cpp
BuffRequest {
    BuffData Info;
    CapturedStatus CasterStatus;      // 施法者状态快照
    CapturedStatus MainTargetStatus;  // 主目标状态快照
    RequestFrom Source;               // 来源
    int32_t Penetration;              // 穿透类型
    double PenetrationRate;           // 穿透率
};
```

### 5.2 Buff倍率变化系统

Buff可以影响各种战斗属性的倍率：

**BuffRateChangeType（Buff倍率变化类型）：**

- MPGain - MP获取倍率

**倍率计算：**

```cpp
总倍率变化 = 0.0

// 遍历所有激活的Buff
for (每个Buff):
    if (Buff.Type == RateChange && Buff.RateChangeType == 目标类型):
        Buff抗性倍率 = GetResistBuffRate(Buff.EffectNo)
        总倍率变化 += Buff抗性倍率 × Buff.Value × Buff.Stack

最终倍率 = max(总倍率变化, 0.0) + 1.0
```

### 5.3 Buff抗性系统

**ResistBuff（抗性Buff）：**
某些Buff可以提供对其他Buff的抗性，减少其效果。

**抗性计算：**

```cpp
// 查找所有抗性Buff
Buff抗性倍率 = 1.0
for (每个抗性Buff):
    if (抗性Buff包含目标Buff编号):
        Buff抗性倍率 += 抗性Buff.Rate

return max(Buff抗性倍率, 0.0)
```

### 5.4 特殊Buff标志

**BuffFlagType（Buff标志类型）：**

- **Invincivble（无敌）** - 免疫所有伤害（除非伤害类型为IgnoreInvincible）
- **ManaDecreaseImmune（MP减少免疫）** - 免疫MP减少效果

**标志检查：**

```cpp
bool HasFlagBuffEffect(BuffFlagType type):
    遍历所有激活的Buff
    if (Buff.State == Active && Buff.FlagType == type):
        return true
    return false
```

### 5.5 Buff叠加与覆盖

**Buff管理机制：**

```cpp
ExistBuffList = BuffList + AddBuffRequestList  // 包含已有Buff和待添加Buff
```

当添加新Buff时：

1. 检查是否存在同组Buff（Group相同）
2. 如果存在且达到叠加上限（OverlapLimit），则刷新持续时间
3. 如果未达到上限，则增加层数（Stack）
4. 应用Buff的穿透属性到Buff效果上

## 7. 穿透系统

### 7.1 穿透类型

**PenetrationType（穿透类型枚举）：**

- **2 - Defence** - 防御穿透
- **3 - Resist** - 抗性穿透
- **4 - All** - 全穿透（同时穿透防御和抗性）

### 7.2 穿透计算

**防御穿透：**

```cpp
if (穿透类型 == Defence 或 All):
    有效防御 = (1 - 穿透率) × 原始防御
else:
    有效防御 = 原始防御
```

**抗性穿透：**

```cpp
if (穿透类型 == Resist 或 All):
    有效抗性 = (1 - 穿透率) × 原始抗性
else:
    有效抗性 = 原始抗性
```

## 8. 被动技能反应系统

### 8.1 被动触发条件

当目标受到交互后，会检查其被动技能：

1. **检查被动技能列表** - 遍历目标的所有被动技能
2. **验证条件** - `IsPassiveConditionClear` 检查被动触发条件
3. **应用反应代码** - 执行被动技能的反应代码（ReactCodes）

### 8.2 触发条件类型

被动技能可以基于以下条件触发：

- 受到伤害
- 造成伤害
- 治疗发生
- Buff添加/移除
- 生命值阈值
- 特定技能类型

## 附录A：公式速查表

### 防御减伤

$$
\text{防御后伤害} = \text{原始伤害} - \frac{\text{有效防御}}{\text{有效防御} + 0.3 \times \text{原始伤害}} \times \text{原始伤害}
$$

### 抗性减伤

$$
\text{抗性后伤害} = \text{防御后伤害} \times \max(1 - \text{有效抗性}, 0.1)
$$

### 最终伤害

$$
\text{最终伤害} = \max((1 + \text{技能倍率}) \times \text{种族相克} \times \text{抗性后伤害} \times \text{暴击系数}, 1)
$$

### 生命值百分比伤害上限

$$
\text{上限} = \text{攻击力} \times 3.0
$$

### MP获取倍率

$$
\text{最终MP} = \text{初始MP} \times (1 + \text{MP获取倍率})
$$
